# NOVA Calculator — iOS 12
Native Swift/UIKit calculator for iPhone 5s. No SwiftUI and no third-party dependencies.
- Persian dark-neon interface
- Full expressions with +, −, ×, ÷, unary signs, and nested parentheses
- Automatic bracket checks and signed-integer evaluation
- Rejects division by zero, non-integer division, invalid expressions, and overflow
Open the Xcode project on macOS. GitHub Actions builds an unsigned IPA and source ZIP. The IPA must be signed before installation. A successful build and testing on iOS 12 are still required to verify device compatibility.
